# 🩸 ALMA & SANGUE  
## Grimório Visceral — Acervo Falado das Pombagiras

**ALMA & SANGUE** é uma aplicação web imersiva e autoral, concebida como um **grimório digital falado**, dedicada ao estudo, respeito e compreensão das Pombagiras sob uma perspectiva espiritual, cultural e simbólica.

O projeto une estética ritualística, narrativa sensorial e tecnologia web para criar uma experiência de escuta, contemplação e aprendizado.

---

## ✨ Propósito

Este projeto tem como objetivos:

- Desmistificar as Pombagiras
- Combater preconceitos religiosos
- Promover conhecimento e respeito cultural
- Centralizar conteúdos audiovisuais organizados por arquétipos
- Criar uma experiência simbólica de “pedido de licença” antes do acesso

> Aqui não habita o medo.  
> Aqui habita a Lei, o Conhecimento e o Respeito.

---

## 🔥 Funcionalidades

- Tela de introdução ritualística (“Pedir Licença”)
- Interface imersiva e responsiva (desktop e mobile)
- Grid dinâmico de entidades e arquétipos
- Player de vídeo integrado (YouTube)
- Tela de detalhes com domínio espiritual e oferendas simbólicas
- Animações atmosféricas (brasas, fade, flicker)
- Design inspirado em grimórios, terreiros e estética gótica

---

## 🧱 Tecnologias Utilizadas

- HTML5  
- CSS3 (animações, variáveis, responsividade)  
- JavaScript Vanilla  
- YouTube Embed  
- Google Fonts (Cinzel, Montserrat)  
- GitHub Pages
